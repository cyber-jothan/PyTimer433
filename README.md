**Пульт для картинга**

Это приложение на PyQt6 для управления картинговыми машинами и светофором через COM-порт (Arduino).

**Что делает:**

- Показывает сетку из 45 машин, разделённых на две зоны: «Парковка» и «Трасса»
- Каждая машина — составная кнопка: верхняя часть запускает машину, стрелки влево/вправо перемещают между зонами
- Отправляет на Arduino RF-код и тайминг в формате `код:тайминг\n`
- «ПУСК МАШИН» — последовательно запускает все машины на трассе с интервалом 0.6 секунды
- «СБРОС» — возвращает все машины на парковку
- «ДЕТСКИЙ» / «ВЗРОСЛЫЙ» — фильтрует машины по суффиксу «д» и выставляет нужные на трассу
- Три кнопки управляют светофором (красный, зелёный, выключить)
- Воспроизводит звук при отправке команды
- Машины раскрашены по группам: красные, жёлтые, синие, зелёные — в зависимости от номера и типа (детская/взрослая)
- Работает в полноэкранном режиме, управление мышкой
